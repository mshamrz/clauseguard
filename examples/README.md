# Зразки B2B-договорів для тестування ClauseGuard

У цій папці зібрано готові файли для перевірки роботи ШІ-аудиту з **чіткою градацією ризиків**:

---

### 1. 🟢 Договір із НИЗЬКИМ ризиком (~20% / Зелений бейдж):
- **`08_Ukrainian_FOP_Low_Risk_20.docx`** / **`договір_it_послуг_низький_ризик_20.docx`**
- **`08_Ukrainian_FOP_Low_Risk_20.pdf`** / **`договір_it_послуг_низький_ризик_20.pdf`**

**Чому тут ризик ~20%:**
-  **Майже ідеальний стандартний контракт:** чіткий ліміт відповідальності, права переходять суворо після 100% оплати, законна пеня НБУ, жодного драконівського Non-Compete.
- ⚠️ **Єдине зауваження для правок:** відтермінування оплати на 60 днів (п. 3.2). ШІ підсвічує саме цей один пункт та радить скоротити строк до 10–15 днів.

---

### 2. 🟡 Договір із СЕРЕДНІМ ризиком (~50% / Жовтий бейдж):
- **`06_Ukrainian_FOP_Medium_Risk_50.docx`** / **`договір_it_послуг_середній_ризик_50.docx`**
- **`06_Ukrainian_FOP_Medium_Risk_50.pdf`** / **`договір_it_послуг_середній_ризик_50.pdf`**

**Чому тут ~50%:**
- ⚠️ Містить 2 помірні зауваження: виплата через 60 днів (п. 3.2), стягнення неустойки 0.5%/день (п. 6.1) та можливість стягнення упущеної вигоди (п. 5.1).
-  Але інтелектуальна власність та ліміт відповідальності захищені.

---

### 3. 🔴 КАБАЛЬНИЙ договір із максимальним ризиком (~95% / Червоний бейдж):
- **`05_Ukrainian_FOP_Contract_Sample.docx`** / **`договір_it_послуг_фоп_зразок.docx`**
- **`05_Ukrainian_FOP_Contract_Sample.pdf`** / **`договір_it_послуг_фоп_зразок.pdf`**

**Чому тут 95%:**
- Включає всі 5 критичних токсичних пасток: необмежену відповідальність за збитки третіх осіб, Pay-When-Paid, відчуження коду до оплати, штраф 40 000 грн + 5% пені за день і заборону на професію на 3 роки.
