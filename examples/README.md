# Зразки договорів для тестування

У цій папці залишено чисті, реалістичні договори у форматах **DOCX** та **PDF** без штучних поміток і підказок:

1. **`contract_software_development_fop.docx`** / **`.pdf`**
   - Договір про надання ІТ-послуг (розробка ПЗ, ФОП 3-ї групи).
   - Стандартний робочий договір з одним практичним пунктом для аудиту (відтермінування виплати на 60 днів).

2. **`contract_design_and_support.docx`** / **`.pdf`**
   - Договір про надання дизайн-послуг та технічної підтримки.
   - Договір із помірними комерційними умовами (відстрочка платежу, неустойка).

3. **`master_services_agreement_en.docx`**
   - Англомовний Master Services Agreement (MSA) для перевірки міжнародних B2B-контрактів.
